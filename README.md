# Portfolio — Health Equity & Design Research

A personal portfolio website built for GitHub Pages.

## 🚀 Deploy to GitHub Pages

1. Create a new repo named `yourusername.github.io`
2. Upload all files from this folder to the root of that repo
3. Go to Settings → Pages → Source: Deploy from a branch → main → / (root)
4. Your site will be live at `https://yourusername.github.io`

## 📁 Files

- `index.html` — Complete single-page portfolio (self-contained, no dependencies)
- `README.md` — This file

## ✏️ Customizing

Open `index.html` and search for these placeholders to update:

- `Your Name Here` → Your actual name
- `your@email.com` → Your email address
- `Your Degree` / `Your University` → Your education details
- LinkedIn URL → Your LinkedIn profile link

## Adding More Projects

Each project is a `<div id="page-projectname" class="page">` section. 
Duplicate the sociodemographic project section and fill in your content.
